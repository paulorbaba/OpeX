Sherpa42
Calculadora de Operação
Como usar
01
Nomeie o projeto
Preencha o nome e a descrição da ativação logo abaixo. Eles aparecem no card exportado.
02
Ative os blocos
Escolha quais tipos de interação fazem sentido para este projeto. Blocos desativados não entram no cálculo.
03
Ajuste as premissas
Use os sliders ou edite os campos diretamente. Títulos e descrições dos blocos também são editáveis — clique em qualquer texto para alterar.
04
Exporte os resultados
O painel branco consolida tudo. Clique em "Gerar card" para exportar um PNG pronto para o slide.
